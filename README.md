# فينانس ساس (Finens SaaS) - لوحة تحكم مالية متعددة الشركات 💼🏢

نظام سحابي متكامل وخفيف مبني بلغة **PHP** لإدارة الخزينة، المصروفات، وبنود الصرف، وحسابات الرواتب لشركات متعددة مع نظام صلاحيات مرن وإمكانية تثبيته كتطبيق موبايل **PWA (Progressive Web App)**.

---

## 🌟 أبرز مميزات النظام

1. **نظام ساس متعدد الشركات (Multi-Tenant SaaS):**
   - **سوبر أدمن (Super Admin):** لوحة تحكم مركزية لمتابعة جميع الشركات، إضافة شركات جديدة، تحديد العملة والرصيد الافتتاحي، وتفعيل أو تعطيل موديولات النظام لكل شركة على حدة.
   - **التبديل الفوري للشركات (Impersonation):** يستطيع السوبر أدمن الدخول بنقرة واحدة كمدير لأي شركة لمعاينة حساباتها وخزينتها دون الحاجة لتسجيل الخروج.
   - **عزل تام لبيانات الشركات:** كل شركة ترى فقط خزينتها ومصروفاتها وتقاريرها ومستخدميها.

2. **التحكم في الموديولات لكل شركة (Module Toggling):**
   - التحكم بما إذا كانت الشركة تمتلك:
     - 🪙 **الخزنة والإيداعات (Treasury & Cash Inflow)**
     - 🧾 **المصروفات اليومية والبنود (Expenses)**
     - 👥 **شؤون الموظفين والمرتبات (HR & Payroll)** *(يمكن تعطيله كما هو الحال في شركة كوكب الصين)*
     - 📊 **التقارير المالية والتحليلات (Reports & Analytics)**

3. **أنواع المستخدمين والصلاحيات:**
   - **سوبر أدمن (`super_admin`):** تحكم كامل في المنصة والشركات.
   - **مدير الشركة (`company_admin`):** إدارة الخزنة والمصروفات والبنود والموظفين ومستخدمي شركته.
   - **مدخل بيانات (`data_entry`):** تسجيل الإيداعات والمصروفات اليومية فقط دون صلاحية تعديل الإعدادات أو حذف السجلات.

4. **إدارة الخزنة والنقدية (Treasury / Safe):**
   - رصيد الخزنة اللحظي مع حماية تلقائية من السحب على المكشوف (Overdraw Protection).
   - تسجيل إيداعات وسحوبات نقدية فورية.
   - كشف حساب حركة الخزنة التفصيلي (Ledger) يوضح الرصيد قبل وبعد كل حركة والمستخدم المسؤول.

5. **المصروفات وبنود الصرف (Expenses & Bands):**
   - بنود مصروفات مرنة (إيجار، فواتير ومرافق، شحن وبضاعة، ضيافة وبوفيه، صيانة...).
   - تسجيل المصروف بسببه ومبلغه وتاريخه وخصمه اللحظي من الخزنة.
   - إمكانية استخراج وطباعة **سند صرف نقدي** معتمد لأي عملية صرف.

6. **الموارد البشرية والرواتب (HR & Payroll - اختياري):**
   - دليل الموظفين والوظائف والرواتب الأساسية.
   - مسيرات الرواتب الشهرية مع احتساب الحوافز والخصومات وصافي الراتب.
   - خصم الرواتب مباشرة من الخزنة كبند مصروفات تلقائي.

7. **تقارير مالية تفاعلية ومقارنة الشهور:**
   - مقارنة السيولة النقدية لآخر 6 شهور (إيداعات مقابل مصروفات).
   - توزيع المصروفات حسب البنود عبر رسوم بيانية تفاعلية (Chart.js).
   - إمكانية طباعة تقارير مالية دورية بضغطة زر.

8. **تطبيق موبايل متقدم (PWA - Progressive Web App):**
   - متوافق 100% مع الهواتف الذكية (تصميم Mobile-First مع شريط تنقل سفلي مثل التطبيقات الأصلية).
   - متاح للتثبيت كأيقونة تطبيق على الشاشة الرئيسية للهاتف (Android عبر Chrome أو iOS عبر Safari).
   - يعمل بسرعة فائقة وبدون أي تعقيد.

9. **إيصالات استلام النقدية وطباعة 3 وصولات A4 (Cash Receipts):**
   - إصدار وصل استلام نقدية وسند قبض فوري برقم ID تسلسلي فريد وثابت لا يتغير (مثل `REC-1001`).
   - تسجيل اسم المستلم تلقائياً من اسم المستخدم الحالي المسجل دخوله (مثل: معاذ).
   - تسجيل بيانات العميل (الاسم، الهاتف، المبلغ، طريقة الدفع، وسبب الاستلام).
   - تفقيط تلقائي للمبلغ باللغة العربية (مثال: فقط خمسمائة جنيه مصري لا غير).
   - خيار إيداع المبلغ في الخزنة تلقائياً بضغطة زر.
   - إمكانية رفع وتغيير شعار المقر/الشركة ليظهر أعلى الإيصال.
   - **تصميم طباعة A4 فاخر يطبع 3 وصولات في ورقة واحدة** (نسخة العميل + نسخة الخزنة والحسابات + نسخة الأرشيف) مع خطوط تنقيط وعلامات قص أنيقة.

## 🔑 الحسابات التجريبية الجاهزة للاختبار

تم تجهيز قاعدة البيانات ببيانات أولية مطابقة لطلبك مباشرة:

| نوع الحساب | اسم المستخدم (Username) | كلمة المرور (Password) | الصلاحيات والشركات |
| :--- | :--- | :--- | :--- |
| **سوبر أدمن المنصة** | `admin` | `admin123` | تحكم كامل بجميع الشركات والموديولات |
| **معاذ (مدير شركة كوكب الصين)** | `china_admin` | `123456` | إدارة شركة كوكب الصين (الخزنة 0.00 ج.م + المصروفات وإيصالات الاستلام) |
| **مدخل بيانات كوكب الصين** | `china_entry` | `123456` | تسجيل المصروفات والإيداعات وإيصالات الاستلام فقط |

> *ملاحظة:* صفحة تسجيل الدخول تحتوي أيضاً على أزرار سريعة لتعبئة بيانات أي حساب بنقرة واحدة!

## 🚀 طريقة التشغيل السريعة

النظام مبني بتقنية **PHP** نقية وخفيفة لا تحتاج لأي حزم خارجية معقدة.

### 1. التشغيل المحلي الفوري (PHP Built-in Server):
افتح مجلد المشروع في منفذ الأوامر (Terminal) وشغل السيرفر المدمج:
```bash
php -S localhost:8000
```
ثم افتح الرابط في المتصفح:
👉 **http://localhost:8000**

### 2. التشغيل على XAMPP / MAMP / cPanel:
- انقل مجلد المشروع إلى مجلد `htdocs` في XAMPP أو `public_html` على الاستضافة.
- يعمل النظام تلقائياً بواسطة **SQLite** دون الحاجة لإنشاء قاعدة بيانات يدوياً (يتم إنشاؤها تلقائياً عند أول تشغيل).
- إذا كنت ترغب في استخدام **MySQL** بدلاً من SQLite، يمكنك ببساطة تعديل ملف `config/database.php`:
  ```php
  define('DB_DRIVER', 'mysql'); // تغيير من sqlite إلى mysql
  define('DB_HOST', '127.0.0.1');
  define('DB_NAME', 'egypt_office_finens');
  define('DB_USER', 'root');
  define('DB_PASS', '');
  ```

## 📱 طريقة تثبيت التطبيق على الموبايل (PWA)

1. افتح رابط لوحة التحكم من متصفح الهاتف (مثلاً `Chrome` على أندرويد أو `Safari` على آيفون).
2. سيظهر لك شريط في أعلى الشاشة: **"تثبيت التطبيق على هاتفك"**، اضغط على **"تثبيت الآن"**.
3. أو من خيارات المتصفح:
   - في أندرويد: اضغط على الثلاث نقاط أعلى الشاشة ثم اختر **"تثبيت التطبيق"** أو **"إضافة إلى الشاشة الرئيسية"**.
   - في آيفون: اضغط على زر المشاركة ثم اختر **"إضافة إلى الشاشة الرئيسية (Add to Home Screen)"**.
4. سيفتح التطبيق بدون شريط المتصفح كـ تطبيق أصلي بكامل الشاشة وبسرعة فائقة.
